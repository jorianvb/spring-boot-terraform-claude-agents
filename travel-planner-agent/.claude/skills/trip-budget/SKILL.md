# Budget consolide de voyage

Produire dans `docs/trips/<voyage>-budget.md` :

```markdown
# Budget : <voyage>

| Poste | Estimation basse | Estimation haute | Source de l'estimation |
|---|---|---|---|
| Transport (aller-retour) | | | |
| Hebergement (total sejour) | | | |
| Repas (total sejour) | | | |
| Activites/visites | | | |
| Assurance voyage | | | |
| Divers / imprevu (10%) | | | |
| **Total** | | | |
```

Toujours ajouter une marge "divers/imprevu" d'au moins 10% du total.
Indiquer clairement la devise utilisee pour chaque montant.
